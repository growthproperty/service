# 物件情報ページ（株式会社グロースプロパティ）

見守りサービス付き・転貸型住宅の物件一覧サイト（静的HTML）。

- `index.html` … 物件一覧（絞り込み・並べ替え）
- `property.html?id=<物件番号>` … お部屋の詳細（個別案内用・noindex）
- `data/rooms.json` … 公開用データ（元賃料は含まない）
- `tools/build_rooms.py` … イタンジBBの取得データ → `data/rooms.json` を生成
- `internal/` … 元賃料との対応表（Git管理外）

## 更新の流れ（2週間に1回）
1. イタンジBBで検索（物件名:レジディア／管理会社:伊藤忠アーバンコミュニティ／賃料15万円以上／申込ありを除く）
2. 取得データを `tools/build_rooms.py` に渡して `data/rooms.json` を再生成
3. commit → push（GitHub Pagesへ自動反映）

## 掲載条件
- 賃料 = 本来の募集賃料 × 1.2（1,000円単位に切り上げ）＋ 見守りサービス 5,000円
- 礼金 = 本来の条件 ＋ 1ヶ月
- 取引態様は「転貸人（貸主）」表記
